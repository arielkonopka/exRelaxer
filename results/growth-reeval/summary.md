# growth-reeval: the growth mechanism on the current library

Runs of `NNtesting/experiments/snake_growth/reeval.py` (research log §37). Defaults of
experiment.py unless the setup says otherwise. `recXX`: E-R recovery 0.5 / 0.75 / 0.9; `shareNN`:
growth triggers at NN% saturated ticks (default 50); `inc4`: 4 neurons per width growth (default 2);
`int8`: 8-bit weights and outputs in the growing layers; `copy`: grown neurons copy active ones
(§35). Long runs: `open` lifts the caps (4,096 wide, 64 deep); `full` is open + `freeze_from=4` +
wide depth growth (`deep_size=0`, `deep_minimum=3`, `prune_base`) + weak pruning, the setup that
matched a fixed ER(16) in §31.

`short.jsonl.gz`: one line per 1,500-game run (format of sweep.py), seeds 1-10. `long.jsonl.gz`: one
line per run until the size is unchanged for 10,000 games (format of long_run.py), seeds 1-5.

    python reeval.py summary results/growth-reeval/short.jsonl.gz

Before these, every run behind §30 (`sweep.py`, 24 runs) and §31 (`long_run.py`, 60 runs) was rerun
on main: all bit-identical (every 50-game score and every size).
